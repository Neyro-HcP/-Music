# НсП Visual Lab

НсП Visual Lab — браузерный конструктор авторских музыкальных визуализаторов. Создавай сцену для трека: форму визуализатора, круглый логотип, собственный фон, виньетку, частицы, свет и движущийся текст.

## Сайт

https://neyro-hcp.github.io/-Music/

## Возможности

- Пять стилей визуализации: спектр, орбитальное кольцо, waveform, aurora и radial core.
- Анализ реальных частот через Web Audio API; логарифмическое распределение частот, быстрые атаки и удержание пиков.
- Реакция басового диапазона на транзиенты и настройка чувствительности, силы удара и плавности.
- Загрузка собственного круглого логотипа и фонового изображения. Эти изображения сохраняются локально в браузере через IndexedDB.
- Отдельное изменение размера, непрозрачности и позиции логотипа.
- Цвета переднего плана и фона, виньетка, количество/размер/скорость частиц.
- Перемещение визуализатора и текста по холсту мышью или касанием и через слайдеры.
- Название и подпись исполнителя с регулируемым размером и позицией.
- Форматы 16:9, 1:1 и 9:16.
- Экспорт видео WebM в реальном времени, сохранение кадра PNG и настроек JSON.
- Аудио обрабатывается локально и не загружается на сервер.

## Ограничения

Экспорт WebM выполняется в реальном времени, а не ускоренным облачным рендерингом: трек должен проиграться полностью, а вкладка оставаться открытой. Доступность записи зависит от браузера и поддерживаемых кодеков. MP4-экспорт не реализован.

Настройки сцены сохраняются через localStorage; пользовательские логотип и фон — отдельно через IndexedDB в текущем браузере. Экспортированный JSON содержит параметры сцены, но не содержит сам аудиофайл и изображения.

## Запуск

Без сервера можно публиковать корневой `index.html` и папку `public/` на статическом хостинге. Для локального сервера Node.js 20+: `npm install`, затем `npm start`, после чего открыть `http://localhost:3000`.

Проверка синтаксиса: `npm run check`.

Используй аудиозаписи, на которые у тебя есть права.
