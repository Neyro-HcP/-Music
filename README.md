# WAVEFRAME — Visual Lab

WAVEFRAME — бесплатный браузерный конструктор аудиовизуализаторов. Загрузи локальный аудиофайл, выбери стиль анимации, настрой цвета и подпись, а затем сохрани видео или PNG-кадр.

## Опубликованный сайт

https://neyro-hcp.github.io/-Music/

## Возможности

- Пять визуальных движков: Neon Spectrum, Orbital, Pure Wave, Aurora и Sonic Core.
- Реакция визуализации на реальные частоты выбранного аудиофайла через Web Audio API.
- Палитры, собственные цвета, цвет фона, чувствительность, свечение и частицы.
- Название трека и подпись исполнителя поверх видео.
- Форматы 16:9 для YouTube, 1:1 для публикаций и 9:16 для Shorts/Reels.
- Запись аудиовизуализатора в WebM в реальном времени прямо в браузере.
- Сохранение PNG-кадра и экспорт настроек проекта в JSON.
- Адаптивный интерфейс для телефона и компьютера.
- Сохранение выбранного стиля локально в браузере.

## Приватность и ограничения

Аудиофайл обрабатывается локально и не загружается на сервер. На этом сайте нет облачного рендеринга: экспорт WebM записывает воспроизведение и кадры в реальном времени. Поэтому длинный трек экспортируется примерно за время его воспроизведения, а браузеру нужно оставаться открытым до завершения записи.

Экспорт WebM зависит от поддержки MediaRecorder и кодеков в браузере. На некоторых мобильных браузерах он может быть недоступен; для лучшей совместимости попробуй обновлённый Chrome или Edge. PNG-кадр можно сохранять отдельно. Экспорт аудио в MP4 пока не реализован.

Настройки «Сохранить стиль» хранятся в localStorage текущего браузера. Файл JSON хранит параметры визуализатора, но не содержит аудио.

## Запуск локально

Вариант без сервера: открой public/index.html в браузере или разверни содержимое папки public/ на статическом хостинге.

Для локального запуска через Node.js (20+) используй npm install, затем npm start, и открой http://localhost:3000. Сервер раздаёт папку public/; аудио для визуализатора всё равно выбирается с устройства пользователя.
