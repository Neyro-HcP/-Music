# НсП Music

Личная музыкальная библиотека НсП: загрузка собственных аудиотреков и обложек, поиск, фильтры, избранное, полноценный нижний плеер и управление публикациями в режиме автора.

Это самостоятельный проект, вдохновлённый современными музыкальными платформами. Это **не клон Suno**: генерация музыки с помощью ИИ пока не входит в MVP.

## Что уже работает

- Адаптивный тёмный интерфейс для телефона и компьютера.
- Загрузка аудио MP3, WAV, M4A, AAC, OGG, FLAC, OPUS и WEBM — до 100 МБ.
- Загрузка обложек JPG, PNG и WEBP — до 8 МБ.
- Название, исполнитель, жанр и описание для каждого релиза.
- Реальное воспроизведение с паузой, переходом между треками, перемоткой и громкостью.
- Поиск, сортировка, фильтры «Все треки», «Недавно добавленные» и «Избранное».
- Режим автора с паролем: загрузка и удаление публикаций.
- Файлы и каталог остаются на сервере в каталоге `data/`.
- Проверка расширения и сигнатуры загружаемых файлов, ограничения размера, rate limit входа и базовые HTTP-заголовки безопасности.

## Запуск на компьютере

Нужен Node.js 20 или новее.

1. Создай файл настроек из примера: `cp .env.example .env` (Windows PowerShell: `Copy-Item .env.example .env`).
2. В `.env` задай собственные значения `ADMIN_PASSWORD` и `SESSION_SECRET`. Не отправляй `.env` в GitHub.
3. Выполни `npm install`, затем `npm start`.
4. Открой `http://localhost:3000` и нажми «Войти как автор».

Проверка синтаксиса: `npm run check`.

## Публичное размещение

Для публикации нужен хостинг, который поддерживает Node.js и **постоянное файловое хранилище**. Добавь переменные `NODE_ENV=production`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `DATA_DIR` (например, `/var/data`) и используй `npm start`.

Важно: на сервере с эфемерной файловой системой загруженные треки могут пропасть после перезапуска или нового развёртывания. Подключи постоянный диск или объектное хранилище перед серьёзным использованием. В этой стартовой версии сессии хранятся в памяти процесса; после перезапуска потребуется войти повторно.
