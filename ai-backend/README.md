# Отдельный backend генератора текстов НсП

Этот каталог разворачивается как отдельный Node.js Web Service. Он нужен потому, что GitHub Pages исполняет только статические файлы и не запускает API.

## Переменные окружения

Настраиваются в панели хостинга, не в браузере и не в Git:

- **AI_API_KEY** — секретный API-ключ выбранного провайдера.
- **AI_API_URL** — HTTPS-адрес OpenAI-compatible Chat Completions endpoint.
- **AI_MODEL** — точный идентификатор модели, поддерживаемый выбранным провайдером.
- **SITE_ORIGIN** — https://neyro-hcp.github.io
- **NODE_ENV** — production.
- **PORT** — платформа задаёт автоматически.

Бесплатная модель зависит от условий конкретного провайдера. Взрослый владелец сервиса должен проверить тариф, требования к возрасту и доступность API в своём регионе. Не указывайте ключ в HTML, JavaScript сайта, репозитории или переписке.

## Развёртывание отдельного API на Render Free

Render запрещает использование сервиса лицами младше 16 лет, а некоторые API-провайдеры требуют 18+. Поэтому учётную запись, ключи и развёртывание должен оформлять и обслуживать взрослый, который соответствует правилам выбранных сервисов. Это отдельный сервис только для генератора; существующий корневой render.yaml не запускайте для этой задачи, потому что он описывает другой сервис с платным тарифом и диском.

1. Взрослый владелец подключает репозиторий Neyro-HcP/-Music в Render и создаёт отдельный Web Service.
2. Root Directory: ai-backend.
3. Build Command: npm install.
4. Start Command: npm start.
5. Выбрать Free.
6. В Environment добавить AI_API_KEY, AI_API_URL, AI_MODEL, SITE_ORIGIN со значением https://neyro-hcp.github.io и NODE_ENV со значением production. Секретный ключ вводится только в защищённые панели провайдера и хостинга.
7. После успешного deploy открыть адрес сервиса с путём /healthz. Ожидаемый ответ: {"ok":true}.
8. На странице генератора GitHub Pages раскрыть «Подключение ИИ», указать только базовый адрес сервиса, например https://имя-сервиса.onrender.com, сохранить адрес и нажать «Проверить подключение».

Бесплатный Render-сервис засыпает после периода бездействия, поэтому первый запрос после паузы может ждать запуска. Бесплатность и лимиты API зависят от выбранного провайдера; проверяйте текущие условия до включения генерации.

## Локальная проверка

Нужен Node.js 20 или новее. Из этого каталога выполнить npm install, задать перечисленные переменные окружения и запустить npm start. Проверка синтаксиса: npm run check.
