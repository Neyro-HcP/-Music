# Отдельный backend генератора текстов НсП

Этот каталог разворачивается как отдельный Node.js Web Service. Он нужен потому, что GitHub Pages исполняет только статические файлы и не запускает API.

## Переменные окружения

Настраиваются только в панели хостинга, не в браузере и не в Git:

- `AI_API_KEY` — секретный API-ключ выбранного провайдера.
- `AI_API_URL` — HTTPS-адрес OpenAI-compatible Chat Completions endpoint.
- `AI_MODEL` — точный идентификатор модели, поддерживаемый выбранным провайдером.
- `SITE_ORIGIN` — `https://neyro-hcp.github.io`.
- `NODE_ENV` — `production`.
- `PORT` — платформа задаёт автоматически.

Бесплатная модель зависит от доступности и условий конкретного провайдера. Перед использованием взрослый владелец API должен проверить тариф, требования к возрасту и доступность сервиса в своём регионе. Не указывайте ключ в `nsp-writer.html`, `public/nsp-writer.js), репозитории или переписке.

## Развёртывание на Render Free

Render запрещает использование сервиса лицами младше 16 лет, а некоторые API-провайдеры требуют 18+. Поэтому учётную запись, ключ и развёртывание должен оформлять и обслуживать соответствующий требованиям взрослый.

1. Взрослый владелец подключает репозиторий `Neyro-HcP/-Music` в Render и создаёт отдельный **Web Service**.
2. Для сервиса указывает **Root Directory**: `ai-backend`.
3. **Build Command**: `npm install`; **Start Command**: `npm start`; тариф **Free**. Не запускайте существующий корневой `render.yaml) для этой задачи: он описывает другой сервис с платным тарифом и диском.
4. В Environment добавляет `AI_API_KEY), `AI_API_URL), `AI_MODEL), `SITE_ORIGIN=https://neyro-hcp.github.io) и `NODE_ENV=production`. Секретный ключ вводится только в защищённую панель провайдера и хостинга.
5. После успешного deploy открывает `https://ИМЯ-СЕРВИСА.onrender.com/healthz) и проверяет ответ `{"ok":true}`.
6. Открывает страницу генератора на GitHub Pages, в блоке «Подключение ИИ» вводит только базовый адрес сервиса, например `https://ИМЯ-СЕРВИСА.onrender.com`, сохраняет и нажимает «Проверить подключение».

Бесплатный Render-сервис засыпает после периода бездействия, поэтому первый запрос после паузы может ждать запуска. Условия бесплатного тарифа и провайдера могут меняться.

## Локальная проверка

Node.js 20+: из этого каталога выполнить `npm install`, задать перечисленные переменные окружения и запустить `npm start`. Проверка синтаксиса: `npm run check`.
